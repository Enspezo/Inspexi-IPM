# B-214 — Footerknoppen van "Asset toevoegen" worden door de bottom-navigatie bedekt en zijn niet klikbaar

- **Testgeval:** INS-09
- **Actor / rol:** Inspecteur / INSPECTEUR
- **App:** Inspexi-App PWA (:5176) · org: inspexidemo
- **Severity:** S3 (matig — primaire CTA onbruikbaar; er is een obscure omweg via het diskette-icoon)
- **Type:** layout/z-index
- **Datum/tijd:** 2026-07-27 09:14

## Verwacht
De knoppen "Annuleren" en "Asset toevoegen" onder in de sheet zijn zichtbaar en klikbaar.

## Werkelijk
De vaste bottom-navigatiebalk (Dashboard / Inspecties / Chat / Instellingen) ligt over de sheet-footer heen.
Een klik op het midden van "Asset toevoegen" belandt op de navigatielink **Chat** — de gebruiker verlaat
het scherm en verliest het ingevulde formulier. Reproduceerbaar op zowel desktop (1280×900) als de
mobile-preset (375×812).

De enige werkende manier om op te slaan is het kleine diskette-icoon rechtsboven in de sheet-header, dat
geen label heeft.

## Reproductie
1. Open een inspectie → klik de ronde **+**-FAB.
2. Scroll naar onderen: "Annuleren"/"Asset toevoegen" zijn (deels) verscholen achter de bottom-nav.
3. Hit-test:
   ```js
   const btn = [...document.querySelectorAll('button')]
     .find(b => b.className.includes('btn-primary') && b.innerText.trim() === 'Asset toevoegen');
   const r = btn.getBoundingClientRect();
   document.elementFromPoint(r.x + r.width/2, r.y + r.height/2);
   ```
   → `<a>` met tekst "1 Chat", `btn.contains(hit) === false`.

## Bewijs
- Desktop 1280×900: `{"btnY":840,"top":"A:1\nChat","isBtn":false}`
- Mobile 375×812: `{"rect":{"x":193.5,"y":752,…},"hitTag":"A","hitText":"1\nChat","isTheButton":false}`
- Screenshot: `bevindingen/img/B-202-asset-toevoegen-geen-types.png` (footer valt samen met de nav)

## Analyse / vermoedelijke oorzaak
`AddAssetSheet.tsx:392` geeft de sheet `z-50`; de bottom-navigatie in `Layout.tsx` heeft eveneens
`z-index: 50` maar staat later in de DOM-volgorde, dus die wint. De sheet is `fixed bottom-0 … max-h-[90vh]`
en houdt geen rekening met de hoogte van de navigatiebalk.

## Advies
1. Geef de sheet (en zijn overlay) een hogere stapelwaarde dan de navigatie (bijv. `z-[60]`), of verberg de
   bottom-nav zolang een sheet open is.
2. Voeg onderaan de sheet een `padding-bottom` ter grootte van de navigatiehoogte toe
   (`pb-[calc(4rem+env(safe-area-inset-bottom))]`).
3. Geef het diskette-icoon een zichtbaar label/aria-label ("Opslaan").
4. Voeg een smoke-assertie toe die voor elke sheet controleert dat `elementFromPoint` op de primaire CTA
   ook daadwerkelijk die knop teruggeeft.

## Status (WP-B2, 2026-07-28): opgelost — PWA-PR Enspezo/InspeXi#34 (fix/wp-b2-asset-tree-ui)

Dekt ook het pre-existing desktop-overlap-punt.
