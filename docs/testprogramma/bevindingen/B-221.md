# B-221 — Fotometadata beschrijven het origineel, niet de opgeslagen gecomprimeerde foto

- **Testgeval:** INS-28
- **Actor / rol:** Inspecteur / INSPECTEUR
- **App:** Inspexi-App PWA (:5176) · org: inspexidemo
- **Severity:** S3 (matig — misleidende data richting server/rapport, geen functieverlies)
- **Type:** inconsistente metadata
- **Datum/tijd:** 2026-07-27 09:36

## Verwacht
De opgeslagen `fileSize`, `width` en `height` beschrijven het bestand dat daadwerkelijk wordt bewaard en
geüpload (gecomprimeerd, max 1920 px, JPEG).

## Werkelijk
De compressie werkt uitstekend — een 4000×3000 PNG van 41,3 MB wordt 1,49 MB JPEG met een thumbnail van
9 kB — maar de metadata worden uit het **originele** bestand gelezen en meegestuurd:

| veld | opgeslagen waarde | werkelijkheid |
|---|---|---|
| `fileSize` | 41.283.787 | 1.490.920 |
| `width` | 4000 | ≤1920 |
| `height` | 3000 | ≤1440 |
| `mimeType` | `image/png` | `image/jpeg` |

Een rapport of beheerscherm dat op deze velden vertrouwt, meldt dus een 41 MB PNG van 4000×3000 waar in
werkelijkheid een 1,5 MB JPEG staat. Ook opslag-/quotaberekeningen kloppen niet.

## Reproductie
1. Open een asset-detail → **Galerij** → kies een grote foto (≥4000 px).
2. Inspecteer het record in IndexedDB (`photos`):
   ```js
   {reportedFileSize: 41283787, actualBlobBytes: 1490920, blobType: "image/jpeg",
    thumbBytes: 9022, width: 4000, height: 3000}
   ```

## Bewijs
Zie de meting hierboven (uitgevoerd met een 4000×3000 ruisafbeelding, PNG 41,3 MB).

## Analyse / vermoedelijke oorzaak
`src/services/photoService.ts` → `processPhoto(file)`:

```ts
const [compressedBlob, thumbnailBlob, metadata] = await Promise.all([
  compressImage(file, 2),
  generateThumbnail(file, 200),
  getImageMetadata(file),      // <-- leest het ORIGINEEL
]);
```

`getImageMetadata()` krijgt het originele `File` mee in plaats van de resulterende blob. `savePhoto()`
combineert vervolgens de gecomprimeerde blob met de originele metadata.

## Advies
1. Bepaal `fileSize`/`width`/`height`/`mimeType` uit `compressedBlob` (of laat `compressImage` de
   uiteindelijke afmetingen teruggeven).
2. Bewaar desgewenst de originele afmetingen apart (`originalWidth`/`originalHeight`) als dat voor
   bewijsvoering nuttig is — maar niet in de velden die de opgeslagen foto beschrijven.
3. Voeg een unit-test toe die na `processPhoto` assert dat `metadata.fileSize === blob.size`.
